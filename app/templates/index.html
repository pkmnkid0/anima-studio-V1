 Natural-language captions

              

                Anima's text encoder is a language model, so a caption written as a sentence
                ("a girl with long blue hair in twintails, wearing a school uniform, smiling in a classroom")
                gives it more to work with than a tag list does. Rephrase tags you already have - instant and
                offline - or let a local vision-language model describe each picture itself.

 Tag variations

                
Different tags for the same thing, like white hair and silver hair. Pick which spelling to keep and every other one is renamed to it.

              

              
            

            

              
              
              
              
              
              
            

            

          


          

            

              

                
 Redundant tags

                
A general tag sitting next to a more specific one, like shirt beside white shirt. Ticked tags are removed only from the captions that also have the specific one.

              

              
            

            

              
              
              
              
              
              
            

            

          


          

            
 Blacklist

            

              Tags you never want in a caption (watermark, signature, text…). Saved with the app, so it is the same next time.
            

            
            

              
              
              
            

            
          


          

            
 Repeated tags

            
Removes a tag that appears twice in the same caption (smile, smile). This is different from variation detection, which finds different tags that mean the same thing.

            
          


          

            
 Tag relationships

            

              See which tags travel together. A tag that is in 95% of your images with the character gets learned as part of her.
              Leave the box empty to list tags that almost always appear as a pair.

     LoRA slimmer
    
          
    Make a smaller copy of a LoRA by cutting its rank, keeping the strongest part of what it learned. The original file is never changed. Works on standard LoRA / LoCon files (not LoHa, LoKr or DoRA).
    
          
    
            
    
              
              
    
                
                
              
    
            
    
            
    
              
              
            
    
          
    
          
    
            
            
            
          
    
          
    
            
    
            
    "Kept" measures how much of the LoRA's change survives, not how it looks. Generate a few test images with the slim copy before deleting anything.
    
            
    
              
              
            
    
          
    
        
    

        
    
          
     LoRA metadata
    
          
    A trained LoRA records how it was made: base model, dataset, training settings. Read that block here, then write a copy with some or all of it removed. The weights are copied byte for byte and hash-checked afterwards, and the original file is never changed.
    
          
    
            
    
              
              
    
                
                
              
    
            
    
            
    
              
            
    
          
    
          
    
            
    
            
    
            
    Ticked keys are kept; everything unticked is dropped from the copy. Tick nothing to ship the file with no metadata at all.

     Install
    
          
    
            Anima Studio's own training backend (native_backend/) needs a couple of
            dependency sets installed once. Click below to run both in sequence: the Anima
            model's own ML stack (PyTorch, etc. - a multi-GB install that has to match your GPU,
            so it can't be frozen into the app itself), then native_backend's SDXL
            dependencies into that same environment. The first part can ask its own questions
            along the way; if it does, type your answer in the box under the log and click Send.

     MOSS-Image trainer
    
          
    
            MOSS-Image trains on its own bundled engine and its own environment (PyTorch 2.14 + CUDA 13), so it never
            touches the Anima/SDXL backend above. Set it up once, then pick
            MOSS-Image on the Train tab and point it at your MOSS-Image model folder. Needs an NVIDIA driver 580+, Git and Python 3.10-3.13 (or uv).
            An 8 GB card trains the full bf16 model with block swap; plan on 32 GB of system RAM.
          
    
          
    
            
            
            
            
            Checking…
          
    
          
    
            
    
          
    
          
    
          
    
        
    

        
    
          
     Low-VRAM trainer (6 GB+)
    
          
    
            A second MOSS-Image engine for small cards (bundled in kohaku_backend; credits in THIRD_PARTY_NOTICES.md).
            It trains straight on the int8 files, streams weights for 6-12 GB cards and has its own kernels. It needs its own
            environment (PyTorch 2.13-2.14 with the CUDA build for your driver, transformers 5.3+), so it never touches the
            other engines. Set it up once, then pick MOSS-Image on the Train tab and switch Trainer engine to
            Low-VRAM trainer. Needs an NVIDIA driver with CUDA 12.6+ and Python 3.10-3.13 (or uv); on Windows install
            Visual Studio Build Tools (C++ workload) for the fast kernels.
          
    
          
    
            
            
            
            
            Checking…
          
    
          
    
            
    
          
    
          
    
          
    
        
    

        
    
          
     AI edit tools
    
          
    
            Powers the AI methods of the Edit tab's Magic eraser: LaMa, Anime LaMa, Manga, ZITS, MAT, FcF, LDM and MI-GAN erasing,

            and face restoration. It runs in its own environment
            (edit_backend/venv, Python 3.10/3.11, PyTorch for your GPU) so its older package pins never touch the other
